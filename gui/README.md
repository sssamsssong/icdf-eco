# 시연 화면

`controller/main.py --gui`가 작은 웹 서버(`controller/server.py`)를 띄우고 이 페이지를 엽니다.
페이지는 0.25초마다 `/state`를 읽어 다시 그립니다. 인터넷 없이 동작합니다 (외부 글꼴·라이브러리 안 씀).

구성
- 위: 제목, 시뮬레이션 시각, [시작]·[구름 올리기] 버튼
- 탄소 그래프: 하루 전 예측(점선), 실제 값(실선), 구름이 있던 시간(붉은 띠)
- 작업 일정: 랙마다 48칸 x 2줄(팬 두 개). 진한 칸은 실행함, 옅은 칸은 예정. D2가 옮긴 칸은 주황 테두리
- 누적 탄소: 두 랙 배출량, 팬 상태, 계획 변경 횟수, 차이
- D2가 바꾼 계획: 언제 어떤 작업을 몇 시로 미뤘는지

화면만 고칠 때는 엔진을 다시 켤 필요 없이 브라우저 새로고침만 하면 됩니다.
