# 아두이노 연결 후 할 일

메인 PC(우분투 데스크톱)에 아두이노 Uno를 USB로 꽂은 뒤 순서대로 진행합니다.
위에서부터 하나씩 체크하면서 내려가세요. 막히면 맨 아래 [문제 해결](#문제-해결)을 보세요.

## 0. 이미 해 둔 것 (2026-11-18)

- [x] `arduino-cli` 1.1.1 설치 (`~/.local/bin/arduino-cli`, 터미널에서 `arduino-cli`로 바로 실행)
- [x] Uno 보드 지원(`arduino:avr` 1.8.8)과 `Adafruit NeoPixel` 1.15.5 라이브러리 설치
- [x] 펌웨어 컴파일 확인 (저장 공간 18%, 메모리 13% 사용)
- [x] 파이썬 가상환경 `icdf-eco/.venv`에 패키지 설치 (pyserial 포함)

Arduino IDE는 따로 설치하지 않아도 됩니다.

## 1. 시리얼 권한 주기 (한 번만)

```bash
sudo usermod -aG dialout yax
```

실행한 뒤 **로그아웃했다가 다시 로그인**해야 적용됩니다. 확인:

```bash
groups        # 목록에 dialout이 있어야 함
```

## 2. 보드 꽂고 포트 찾기

```bash
arduino-cli board list
```

- 정품 Uno는 보통 `/dev/ttyACM0`, 호환 보드(CH340 칩)는 `/dev/ttyUSB0`로 보입니다.
- 아무것도 안 나오면 [문제 해결](#문제-해결)의 "포트가 안 보임"을 보세요.

아래 명령에서는 `/dev/ttyACM0`으로 적었습니다. 다르면 바꿔서 쓰세요.

## 3. 펌웨어 올리기

```bash
cd ~/icdf-eco
arduino-cli compile --fqbn arduino:avr:uno firmware/fan_led
arduino-cli upload -p /dev/ttyACM0 --fqbn arduino:avr:uno firmware/fan_led
```

`New upload port` 또는 아무 오류 없이 끝나면 성공입니다.
펌웨어를 고쳤을 때도 이 두 줄을 다시 실행하면 됩니다.

## 4. 손으로 하나씩 시험하기

```bash
arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200
```

연결되면 `READY`가 보입니다. 아래를 한 줄씩 입력하고 Enter를 칩니다.

| 입력 | 기대 결과 | 확인 |
|---|---|---|
| `1 1` | 팬 1번 (B 랙, D3) 돌기 시작, `OK fan 1 on` | [ ] |
| `1 0` | 팬 1번 멈춤 | [ ] |
| `2 1` / `2 0` | 팬 2번 (B 랙, D5) | [ ] |
| `3 1` / `3 0` | 팬 3번 (D2 랙, D6) | [ ] |
| `4 1` / `4 0` | 팬 4번 (D2 랙, D11) | [ ] |
| `9 0` | LED 바 초록 | [ ] |
| `9 50` | LED 바 노랑 | [ ] |
| `9 100` | LED 바 빨강 | [ ] |

- 팬이 **B 랙 쪽 2개, D2 랙 쪽 2개**로 맞게 배치되어 있는지 꼭 확인하세요. 바뀌어 있으면 시연에서 반대 랙 팬이 돕니다.
- 끝나면 **Ctrl+C로 모니터를 닫으세요.** 열어 둔 채로는 시연 엔진이 포트를 쓸 수 없습니다.

## 5. 시연 엔진과 같이 돌리기

먼저 아두이노 없이 화면만 확인합니다.

```bash
cd ~/icdf-eco
source .venv/bin/activate
python -m controller.main --day 2025-03-10 --ours --gui --dry-run
```

브라우저가 열리고 [시작]을 누르면 그래프가 움직이면 정상입니다. 터미널에서 Ctrl+C로 끕니다.

이제 아두이노를 붙여서 실행합니다.

```bash
python -m controller.main --day 2025-03-10 --ours --gui --port /dev/ttyACM0
```

- [ ] 화면 아래쪽에 `아두이노 /dev/ttyACM0`이 표시됨
- [ ] [시작]을 누르면 화면의 팬 아이콘과 실제 팬이 같이 켜지고 꺼짐
- [ ] LED 바 색이 화면의 탄소 값에 따라 바뀜 (낮으면 초록, 높으면 빨강)
- [ ] [구름 올리기]를 누르면 LED가 빨간 쪽으로 바뀜
- [ ] 하루가 끝나면 팬과 LED가 모두 꺼짐
- [ ] Ctrl+C로 끄면 팬과 LED가 모두 꺼짐

빠르게 여러 번 확인하고 싶으면 `--slot-seconds 0.5`를 붙이세요 (하루 24초).

## 6. 마무리 점검

- [ ] 20분 이상 계속 돌려도 팬이 멈추거나 USB 연결이 끊기지 않는지 (리허설과 같이)
- [ ] 팬 12V 어댑터, LED 5V 어댑터, 아두이노 USB를 모두 뽑았다 다시 꽂아도 같은 포트로 잡히는지
- [ ] 부스 배치 그대로 케이블이 당겨지지 않는지

## 알아 둘 점

- **포트를 열면 아두이노가 재시작됩니다.** 시연 엔진은 연결 후 2초 기다렸다가 명령을 보내므로 정상입니다.
- **엔진이 갑자기 죽으면 팬이 켜진 채로 남을 수 있습니다.** 펌웨어에 자동 꺼짐 기능이 아직 없습니다. 이럴 땐 엔진을 다시 켜거나 아두이노 USB를 뽑았다 꽂으세요.
- **터미널 단축키(`s`, `c`, `q`)는 리눅스에서 동작하지 않습니다.** Windows 전용 코드라서입니다. 대신 브라우저 화면의 버튼, 스페이스(구름), Enter(시작)를 쓰고, 끌 때는 터미널에서 Ctrl+C를 누릅니다.
- 배선은 [팬_LED_배선도_레버3개.png](팬_LED_배선도_레버3개.png), 하드웨어 전체 연결은 [하드웨어_연결도_정보흐름.png](하드웨어_연결도_정보흐름.png)를 보세요.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `Permission denied: '/dev/ttyACM0'` | 1번(dialout)을 안 했거나 다시 로그인을 안 함 |
| 포트가 안 보임 (`board list`가 비어 있음) | 데이터 전송이 안 되는 충전 전용 USB 케이블일 수 있음 → 다른 케이블. 호환 보드면 `sudo apt remove brltty` 후 다시 꽂기 |
| `Device or resource busy` | 시리얼 모니터나 다른 엔진이 포트를 열고 있음 → 닫기 |
| 업로드 중 `not in sync` 오류 | 보드 종류나 포트가 틀림. 오래된 호환 보드면 `--fqbn arduino:avr:nano:cpu=atmega328old` 등 확인 |
| 팬이 안 꺼짐 | 팬 PWM 선이 아닌 3핀 가지가 연결됐는지, GND가 아두이노와 공통인지 확인 (진행상황.md의 팬 문제 해결 참고) |
| LED 바가 깜빡이거나 색이 이상함 | 5V 어댑터 GND와 아두이노 GND가 이어져 있는지, D7의 330Ω 저항과 1000µF 콘덴서 확인 |
| 모니터에 글자가 깨져 보임 | 속도(baudrate)를 115200으로 맞췄는지 확인 |
