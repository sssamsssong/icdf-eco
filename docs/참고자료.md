# 영국 탄소 집약도 데이터 참고자료

## 링크

| 자료 | 주소 | 용도 |
|---|---|---|
| Carbon Intensity API 문서 | https://carbon-intensity.github.io/api-definitions/ | 모든 엔드포인트와 응답 형식 |
| API 기본 주소 | https://api.carbonintensity.org.uk/ | 실제 호출 |
| Carbon Intensity 소개 사이트 | https://carbonintensity.org.uk/ | 데이터 설명, 출처 |
| 예측 방법론 (PDF) | https://github.com/carbon-intensity/methodology/raw/master/Regional%20Carbon%20Intensity%20Forecast%20Methodology.pdf | 영국 측 forecast가 어떻게 만들어지는지 |
| NESO 데이터 포털 | https://www.neso.energy/data-portal | 발전원별 이력 등 추가 데이터 (브라우저로 열기) |

- API 키가 필요 없습니다. 라이선스는 CC BY 4.0이라 출처만 밝히면 됩니다.
- 시각은 모두 UTC입니다(`Z`).
- 단위는 gCO₂/kWh, 간격은 30분입니다.

## 자주 쓸 엔드포인트

| 요청 | 의미 |
|---|---|
| `GET /intensity` | 지금 30분 구간의 forecast와 actual |
| `GET /intensity/{from}/{to}` | 기간 조회. **한 번에 최대 31일** |
| `GET /intensity/{from}/fw48h` | `from`부터 48시간 앞 예측 |
| `GET /intensity/{from}/pt24h` | `from`부터 24시간 전까지 |
| `GET /generation/{from}/{to}` | 발전원별 비율 (가스, 풍력, 원자력 등) |

예시 (브라우저 주소창에 붙여 넣어도 됩니다):

```
https://api.carbonintensity.org.uk/intensity/2024-01-01T00:00Z/2024-01-02T00:00Z
```

응답 형식:

```json
{"data":[{"from":"2024-01-01T00:00Z","to":"2024-01-01T00:30Z",
          "intensity":{"forecast":64,"actual":60,"index":"low"}}]}
```

## 주의할 점

- **기간 조회는 31일이 최대**입니다. 그보다 길면 `400 Bad Request`가 납니다. `data/fetch_uk_carbon.py`가 30일씩 나눠 받습니다.
- 데이터는 2017년 9월부터 있습니다.
- 과거 구간의 `forecast` 값은 하루 전 예측이 아니라 직전에 낸 단기 예측으로 보입니다. 그래서 B 랙의 "하루 전 예측"으로 그대로 쓰면 오차가 실제보다 작게 나옵니다. 하루 전 예측은 우리 모델로 만들거나, `fw48h`를 매일 저장해 쌓아야 합니다.
- `actual` 값도 사후 추정치입니다. 발표 때 한계로 밝힙니다.
- 가끔 `actual`이 `null`인 구간이 있습니다. 앞뒤 값으로 채우거나 그 날을 빼야 합니다.
