# 발표 시연 시나리오

세 시나리오는 `controller/scenarios.py`에 정해 두었습니다. 날짜, 작업 큐(무작위지만 seed가 고정), 구름 시간이 같아서 리허설과 발표에서 똑같은 장면이 나옵니다.

```bash
icdf 1      # 시나리오 1 · 긴 구름          (하루, 약 50초, 구름 자동)
icdf 2      # 시나리오 2 · 짧은 구름 여러 번 (하루, 약 50초, 구름 자동)
icdf 3      # 시나리오 3 · 직접 올려 보기    (5일 연속, 약 4분, 구름판·버튼으로 직접)
```
시나리오를 바꿀 때는 Ctrl+C로 끄고 다른 번호로 다시 켭니다. 화면에서 Enter(또는 [시작])를 누르면 재생됩니다.
속도는 시나리오마다 30분 한 칸 = 1초입니다. 바꾸려면 `icdf 1 --slot-seconds 1.5`처럼 (숫자가 클수록 느림). 리허설로 더 빨리: `icdf 1 --rehearsal` (하루 약 24초).

화면 위 주황 표시에 지금 시나리오 이름이 나옵니다. 시나리오 1, 2에서는 구름이 자동으로 들어가서 [구름 올리기] 버튼과 조도센서가 꺼져 있습니다 ("구름 자동").

## 공통: 작업 큐

- 작업은 하루마다 무작위로 9~13개입니다. 긴급 작업 1~2개와 유연한 작업(학습, 추론, 배치, 분석)이고, 도착 시각, 길이(1~4시간), 마감이 제각각입니다.
- 두 랙(Google, YAX)은 **같은 작업, 같은 마감, 같은 하루 전 예측**으로 시작합니다. 다른 것은 당일에 계획을 고치는 방식뿐입니다.
- 화면의 누적 탄소에는 계획 변경 1회당 4.5 g(가정)이 포함되어 있습니다.

## 시나리오 1 · 긴 구름

| 항목 | 값 |
|---|---|
| 날짜 | 영국 전력망 2025-09-14 |
| 구름 | 03:00 ~ 08:30 (6시간), 탄소 +120 |
| 결과 | Google 1,521 g (구름 속 9칸 실행) / **YAX 1,285 g** (6번 미룸, 구름 속 3칸) → **15.5% 적게** |

**보여 줄 것**
1. 03:00에 구름이 생기면 판단 3단계의 1번이 빨간 숫자(+120 근처)로 바뀝니다.
2. 2번에서 AI 모델이 "이 오차가 몇 시간 이어진다"고 예측하고, 그래프에 주황 선(AI가 다시 본 예측)이 생깁니다.
3. 3번이 "미룸"으로 바뀌면 YAX 팬(3, 4번)이 멈추고, 일정 줄에 점선(비운 자리)과 화살표가 생깁니다. Google은 구름 속에서도 빨간 칸으로 계속 실행합니다.
4. 미룬 작업은 저녁의 깨끗한 시간(초록 칸)에 실행됩니다.

**말할 것**: "하루 전 계획이 틀렸을 때, Google 방식은 그대로 실행하고 YAX는 AI가 오차가 이어질지 예측해서 이득이 클 때만 미룹니다."

## 시나리오 2 · 짧은 구름 여러 번

| 항목 | 값 |
|---|---|
| 날짜 | 영국 전력망 2025-06-07 |
| 구름 | 07:00, 10:30, 13:30, 18:00, 20:30에 30분~1시간씩 (5번) |
| 결과 | Google 1,326 g / **YAX 1,293 g** (**1번만** 바꿈) → 2.5% 적게 |

**보여 줄 것**
1. 구름이 5번 지나가는 동안 YAX의 판단 3단계는 대부분 "유지"입니다 (이득이 변경 비용 10 g보다 작음).
2. 계획 변경은 하루 1번뿐입니다. 정말 이득이 큰 한 번만 옮깁니다.

**말할 것**: "구름이 잠깐 지나갈 때마다 계획을 뒤집으면 운영이 불안정해지고 변경 비용이 쌓입니다. YAX는 흔들리지 않고, 꼭 필요할 때만 바꿉니다."

**참고 (화면에는 없음)**: 같은 조건에서 지금 오차에만 반응하는 방식(Reactive)은 12번 바꾸고 1,368 g으로 Google보다도 나빠집니다. 질문이 나오면 말하세요.

## 시나리오 3 · 직접 구름을 올려 보세요

| 항목 | 값 |
|---|---|
| 날짜 | 2025-09-14부터 5일 연속 (하루 약 50초, 전체 약 4분) |
| 작업 | 날마다 다른 무작위 작업 큐 |
| 구름 | 정해 두지 않음. 심사위원이 조도센서 위에 구름판을 올리거나, 화면의 [구름 올리기]를 누름 |

**진행**
1. **시작할 때는 센서를 가리지 마세요.** [시작]을 누르는 순간의 밝기가 기준입니다 (첫날에만 잼).
2. 심사위원에게 구름판을 건네고, 원하는 때에 올렸다 내렸다 하게 합니다. 반투명 판은 얇은 구름, 불투명 판은 두꺼운 구름입니다 (가린 비율만큼 탄소 +, 최대 +150).
3. 화면 오른쪽 위 "빛 가림 62% → 탄소 +93"으로 지금 구름 세기가 보입니다.
4. 하루가 끝나면 3초 뒤 다음 날로 넘어가고, 누적 탄소는 **지난날까지 합계**로 이어집니다 ("3일째까지 합계").

**미리 알아 둘 것**
- 짧게, 얇게 가리면 YAX는 대부분 "유지"합니다. 정상 동작입니다 (이득 < 비용).
- 작업이 없는 시간에 가리면 아무 일도 안 일어납니다. 그래프 아래 일정 줄에서 칸이 차 있는 시간을 보고 가리라고 안내하세요.
- 구름이 중간에 걷히는 장면에서는 이득이 작게 나올 수 있습니다. 실제 성능은 화면 맨 아래 685일 검증 줄로 말하세요.
